## Краткий вывод по первому ноутбуку
Самым неочевидным было применить маску до softmax, чтобы запрещённые
позиции получили нулевой вес, а остальные в сумме дали единицу.
Если обнулить запрещённые веса после softmax, часть вероятности уже будет распределена по запрещённым позициям, и после обнуления сумма оставшихся весов окажется меньше единицы.
А Если же заранее подставить −inf в запрещённые логиты, softmax присвоит этим позициям нулевой вес и распределит всю вероятность между разрешёнными.
