# ДЗ 1. Внимание и поиск ошибок

## Как воспроизвести результаты

1. Скачайте файлы и откройте гугл коллаб. Там окружение готово для прогона ноутбуков.
2. Откройте `dz1-attention.ipynb` и выполните все ячейки сверху вниз.
   Ожидаемый результат — 17 из 17 пройденных проверок.
3. Откройте `dz1-bughunt.ipynb` и выполните все ячейки сверху вниз.
   Ожидаемый результат — 17 из 17 пройденных проверок.
   Обучение выполняется 600 шагов. В сохранённом прогоне потери
   снизились с 3,184 до 0,037.

## Где смотреть результаты

- Таблица трёх ошибок с номерами строк, объяснениями и исправлениями
  находится в разделе «Разбор ошибок» второго ноутбука.
- График потерь и пример сгенерированного текста сохранены
  в выводе последних ячеек второго ноутбука.
